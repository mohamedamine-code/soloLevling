# build resources

This folder holds Windows packaging assets. `build/icon.ico` (16–256 multi-size) and
`build/icon.png` are generated by `node scripts/generate-icons.mjs` and are consumed
by `electron-builder.yml` (installer icon, tray/window icon via `extraResources`).

The full installer is built with `npm run dist` (electron-vite build + electron-builder
NSIS) and lands in `dist/sololeving-<version>-setup.exe`.
